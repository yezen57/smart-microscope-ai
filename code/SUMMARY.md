# 🔬 مصنف خلايا الدم البيضاء - الملخص النهائي

تم إنشاء عدة واجهات لتصنيف خلايا الدم البيضاء باستخدام الذكاء الاصطناعي

## 🎯 الهدف

تطوير نظام ذكي لتصنيف وتحليل خلايا الدم البيضاء من صور الميكروسكوب، مع توفير واجهات متعددة لتناسب احتياجات مختلفة.

## 📦 المكونات المتوفرة

### 1. 🖥️ واجهة رسومية (Tkinter)
- ملف: `simple_classifier_interface.py`
- سهلة الاستخدام للأشخاص غير الفنيين
- عرض مرئي للنتائج
- مناسبة للاستخدام على أجهزة الكمبيوتر

### 2. 💻 واجهة سطر الأوامر
- ملف: `classify_image_cli.py`
- سريعة وفعالة
- مناسبة للدمج في سكريبتات
- عرض النتائج في الطرفية

### 3. 🌐 واجهة ويب (Flask)
- ملف: `web_classifier.py`
- يمكن الوصول إليها عبر المتصفح
- تصميم جذاب ومتجاوب
- مناسبة للاستخدام في الشبكة المحلية

### 4. ☁️ Google Colab
- ملفات: `colab_classifier.py`, `colab_setup.py`
- يعمل في بيئة سحابية
- لا يتطلب تثبيت محلي
- مناسب للتعلم والتجريب

## 🚀 كيفية الاستخدام

### لل сред المحلي:
1. تأكد من تثبيت المكتبات المطلوبة:
```bash
pip install -r requirements.txt
```

2. اختر الواجهة المناسبة:
```bash
# واجهة رسومية
python simple_classifier_interface.py

# واجهة ويب
python web_classifier.py

# واجهة سطر الأوامر
python classify_image_cli.py path/to/image.jpg
```

### للـ Google Colab:
1. نفذ ملف الإعداد:
```python
!python colab_setup.py
```

2. استخدم `colab_classifier.py` للتصنيف

## 📊 النموذج المدرّب

- ملف: `best_model.h5`
- مبني على EfficientNetB3 مع Transfer Learning
- مدرب على مجموعة بيانات Naturalize 2K-PBC
- يدعم 11 فئة من خلايا الدم البيضاء

## 🧪 الفئات المدعومة

1. Basophil (الحبوب القاعدية)
2. Banded Neutrophil (العصبات الحلزونية)
3. Eosinophil (الحبوب الحمضية)
4. Erythroblast (الخلايا الدم الحمراء الجنينية)
5. Lymphocyte (الخلايا اللمفاوية)
6. Meta-myelocyte (الخلايا النخاعية المتوسطة)
7. Monocyte (الخلايا الوحيدة)
8. Myelocyte (الخلايا النخاعية)
9. Platelet (الصفائح الدموية)
10. Pro-myelocyte (الخلايا النخاعية الأولية)
11. Segmented Neutrophil (العصبات المقسّمة)
